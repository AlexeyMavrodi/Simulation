# 🧬 Симуляция 2D мира

> Пошаговая симуляция экосистемы: травоядные ищут траву, хищники охотятся на травоядных.

## 🧠 О проекте

Это консольное приложение, моделирующее жизнь на двумерной карте N x M. Каждая клетка может содержать:

- 🌿 **Траву** — ресурс для травоядных
- 🦓 **Травоядное** — двигается в сторону травы, поедает её
- 🦁 **Хищник** — охотится на травоядных
- 🗿 **Скала** / 🌳 **Дерево** — статические препятствия

Симуляция пошаговая: на каждом ходу все существа совершают действия в порядке очереди.
